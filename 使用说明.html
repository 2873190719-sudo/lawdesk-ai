LawDesk AI · 使用说明律师个人智能业务管理工作台 · 单机独立版

0先弄清楚：这是单机版

整套系统只在你自己的电脑上运行，所有案件、客户、合同、文书、证据、附件都保存在本机硬盘，不会上传到任何服务器，也不会联网同步。

因此每个人的数据都是各自独立的：你和给你这份程序的朋友各用各的，互相看不到对方的数据。如果需要把某批资料交给对方，用系统里的「系统设置 → 导入导出」或「备份与恢复」手动传文件即可。

页面刷新、关掉重开、重启电脑，数据都会保留。只有删除 data/ 目录才会真正丢失资料。

1准备环境

需要 Python 3.9 或更高版本（无需安装任何第三方库，也无需联网）。

  • Windows：到 python.org 下载安装，安装时勾选 “Add Python to PATH”；或在命令行输入 python --version 确认已有。
  • macOS / Linux：系统通常自带，命令行输入 python3 --version 确认。

2启动

1
Windows 解压后双击 start.bat。会弹出一个黑色命令行窗口，使用期间不要关闭它。
2
macOS / Linux 在终端进入本目录，执行 bash start.sh。
3
浏览器打开 http://127.0.0.1:8765，会自动进入工作台，无需手动登录。
4
不用了就关闭命令行窗口（或按 Ctrl + C）停止服务，数据仍在硬盘上。
初始账号与密码会显示在 start.bat / start.sh 的启动提示里。首次使用请到「系统设置 → 账户与偏好」修改密码，避免他人打开你的电脑直接进入。

3数据在哪 / 怎么备份

内容位置
全部业务数据（SQLite 关系型数据库）data/lawdesk.db
上传的合同、证据、附件原件data/uploads/
自动备份（含数据库 + 全部附件）data/backups/

建议在「系统设置 → 备份与恢复」里定期点一次「创建备份」，并把整个 data/ 目录另存到移动硬盘或加密网盘。恢复备份会覆盖当前全部数据，操作前系统会二次确认。

不要把 data/ 放进网盘「实时同步」的目录：数据库文件在程序运行时被同步，可能损坏。要同步就先停止服务，再复制整个目录。

4功能速览

  • 16 个模块：案件、客户、合同、文书中心、法律检索、证据、保全管理、常法客户、日程与期限、工时计费、知识库、AI 法律助手、经营分析等。
  • 所有列表都支持新增、编辑、删除（二次确认）、搜索、筛选、排序、表格/卡片切换、批量操作、导入导出；误删可从「回收站」恢复，重要操作可在「操作日志」撤销。
  • 模块之间数据互通：选客户自动带入资料、开庭日程同步案件关键日期、收款实时更新经营统计、文书自动归档到案件。
  • 快捷键：Ctrl + K 全局搜索，Esc 关闭弹窗，顶部计时器在任何页面都能用。
  • AI 助手默认使用「本地上下文模式」，只读取系统里已录入的资料并生成草稿与建议，不编造法条、司法解释或判例；如需生成式回答，可在「系统设置 → AI 配置」自行接入大模型接口。
保全到期日、诉讼期限的辅助计算仅供参考，必须以实际裁定书、适用法律及具体案件情况为准；AI 生成内容与法律检索结果均须律师核验后方可作为正式依据。

5常见问题

现象处理
双击 start.bat 一闪而过 / 提示找不到 Python未安装 Python 或没勾选 Add to PATH。装好后重开；也可在本目录命令行执行 python server.py 查看报错。
提示端口被占用先关闭已经开着的启动窗口；或设置环境变量换端口，例如 Windows 命令行执行 set LAWDESK_PORT=8766 && python server.py，然后访问 http://127.0.0.1:8766。
朋友想从另一台电脑访问这个版本刻意只监听本机地址，不支持跨设备直接访问。请给对方一份同样的分发包，让他在自己电脑上运行；需要协同办案则需另外部署服务端版本。
想换账号 / 多人共用一台电脑「系统设置 → 账户与偏好 → 切换 / 注册账号」，每个账号的数据彼此隔离。
